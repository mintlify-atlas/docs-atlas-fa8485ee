AutoFix is an autonomous code self-healing engine powered by Google Gemini AI. Point it at broken Python code, provide functional requirements, and a team of specialized AI agents will write tests, execute them in an isolated sandbox, analyze failures, and patch your code — iterating until every test passes.

## What AutoFix Does

AutoFix bridges the gap between QA testing and software engineering by running a fully autonomous repair loop:

<Steps>
  <Step title="Generate Tests">
    The **Test Engineer Agent** uses Google Gemini to synthesize a comprehensive `pytest` suite from your functional requirements and target source code.
  </Step>
  <Step title="Execute in Sandbox">
    Tests run in an isolated Python subprocess sandbox with a configurable timeout. AutoFix captures all `stdout`/`stderr` output and exit codes.
  </Step>
  <Step title="Diagnose & Patch">
    If tests fail, the **Healer Agent** analyzes the traceback and generates a complete corrected implementation. The patched code is written back to the sandbox and re-tested.
  </Step>
  <Step title="Verify & Report">
    AutoFix iterates up to `MAX_HEALING_ITERATIONS` times. On completion it produces a structured Markdown audit report showing per-test initial vs. final status — perfect for GitHub PR comments.
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Dual AI Agents" icon="robot">
    Specialized **Test Engineer** and **Healer** personas with distinct system prompts tuned for pytest generation and Python debugging.
  </Card>
  <Card title="AST Dependency Analysis" icon="sitemap">
    `RepoAnalyzer` builds a Python import graph via the `ast` module, feeding relevant context to the Healer for accurate multi-file repairs.
  </Card>
  <Card title="GitHub App Integration" icon="plug">
    Listens to `pull_request` webhook events, clones repos, commits patches, and posts formatted audit reports as PR comments automatically.
  </Card>
  <Card title="LLM Fallback Tiering" icon="layer-group">
    Automatic model fallback with retry logic for 503/429 errors across multiple Gemini model tiers — no dropped requests under load.
  </Card>
</CardGroup>

<Note>
  AutoFix currently supports **Python** projects. The sandbox adapter is designed to be extended to additional languages via the `BaseSandboxAdapter` interface.
</Note>
